Step 1 · Search strategy

Search strategy

Compose a Boolean query with field tags, pick a database, and run it. Every parameter — including the exact query string — is written to the methodology log.

Discard raw query edits?

The Query Builder regenerates the query from its fields, so your hand-edited raw query will be lost. Copy it first if you want to keep it.
